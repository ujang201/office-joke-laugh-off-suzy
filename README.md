# Office Joke Laugh-Off — Suzy

One-line office joke entry for the make.fun bounty
**One-Line Office Joke Laugh-Off** (`u-suzy-one-line-office-joke-laugh-off-f574ac73`).

## The joke

> My boss said AI could never replace me — then asked me to train the AI that will replace me.

## How it works

`main.ts` is a small deterministic TypeScript program (Node 22, no
dependencies, no randomness, no clock, no network, no input). When run it
writes exactly one line — the joke above, 92 characters, no trailing
newline — to `/output/entry.txt`, the path the competition gate checks
(UTF-8 text, 1–200 characters, a single line about office life).

Run it with:

```sh
node main.ts
```

## Files

- `main.ts` — the entry program
- `prompt.txt` — the prompt used to write the joke
